| G-11 | The gateway reply format and Bengali delivery are unconfirmed | No reply sample was shared | A send counts as failed on a transport error, a non-2xx status, or a 2xx reply whose text contains an error marker (`error`, `fail`, `invalid`, `wrong`, `denied`, `unauthori`, `reject`, `insufficient`, `not allowed`, `blocked`, `expired`). JSON replies are judged by their string values (never key names) plus `success`/`ok` = `false`. A refusal worded otherwise counts as sent (the user sees `auth.sms_delayed` and resends). A success that contains a marker word is retried ×5, sending the same code again. Still open: delivery past SAS. Owner: look up `Message_ID` 4117517 in the SAS panel delivery report, and send an English-only test from the panel to the same number. If English arrives and the Bengali OTP does not, ask SAS for its Unicode parameter, or switch the OTP SMS to English |
